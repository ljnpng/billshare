# Upload-First Flow Design

## 概述

将 BillShare 的流程从"先添加人员再上传账单"改为"先上传账单再决定是否分账"，支持 0-1 人的纯账单查看模式。

## 流程变化

```
旧流程: Setup (人员) → Input (账单) → Assign → Summary

新流程: Input (账单+人员) → [Assign] → Summary
                            ↑
                     仅 2+ 人时出现
```

### 核心逻辑

| 人数 | 流程 | Summary 展示 |
|------|------|-------------|
| 0-1 人 | Input → Summary | 账单卡片 + 总计 |
| 2+ 人 | Input → Assign → Summary | 完整分账结果 |

## 页面设计

### Input 页面（首页）

**无账单时（首次进入）：**

```
┌─────────────────────────────────────┐
│                                     │
│            📄 / 📸                  │
│                                     │
│      [  AI 识别上传账单  ]           │  ← 主要 CTA
│                                     │
│         或 手动输入                  │  ← 次要链接样式
│                                     │
└─────────────────────────────────────┘
```

- 极简首屏，聚焦 AI 上传
- 手动输入作为次要选项，不起眼

**有账单时：**

```
┌─────────────────────────────────────┐
│    账单卡片 1                        │
│    账单卡片 2                        │
│    ...                              │
│    [+ AI 识别] [+ 手动添加]          │  ← 列表底部
├─────────────────────────────────────┤
│  ▶ 需要分账？点击添加人员            │  ← 折叠区域，默认收起
├─────────────────────────────────────┤
│  [返回首页]          [查看汇总/分配] │
└─────────────────────────────────────┘
```

**按钮文案逻辑：**
- 0-1 人 → "查看汇总"
- 2+ 人 → "分配账单"

**按钮启用条件：**
- 至少有 1 个账单项目时启用

### Summary 页面（0-1 人模式）

```
┌─────────────────────────────────────┐
│  账单卡片 1                          │
│  ┌─────────────────────────────────┐│
│  │ 商家名称                        ││
│  │ ─────────────────────────────── ││
│  │ 商品 A                    $10.00││
│  │ 商品 B                    $15.00││
│  │ ─────────────────────────────── ││
│  │ 小计          $25.00            ││
│  │ 税费           $2.50            ││
│  │ 小费           $5.00            ││
│  │ 总计          $32.50            ││
│  └─────────────────────────────────┘│
│                                     │
│  账单卡片 2 ...                      │
├─────────────────────────────────────┤
│  所有账单总计              $65.00   │
├─────────────────────────────────────┤
│  [返回]                             │
└─────────────────────────────────────┘
```

**与 2+ 人模式的区别：**
- 没有"个人账单"分账结果
- 没有"谁付给谁"的结算建议
- 纯粹的账单明细展示

### Assign 页面（仅 2+ 人）

基本保持现有逻辑：

```
┌─────────────────────────────────────┐
│  账单卡片（可展开）                   │
│  ┌─────────────────────────────────┐│
│  │ 商品 A    $10.00   [人员选择]   ││
│  │ 商品 B    $15.00   [人员选择]   ││
│  └─────────────────────────────────┘│
├─────────────────────────────────────┤
│  [返回]                  [查看结果] │
└─────────────────────────────────────┘
```

## 移除的内容

- `SetupStep` 组件（人员管理合并到 Input 页面）
- `StepIndicator` 组件（去掉步骤指示器）

## 状态管理变化

### currentStep 类型

```typescript
// 旧
currentStep: 'setup' | 'input' | 'assign' | 'summary'

// 新
currentStep: 'input' | 'assign' | 'summary'
```

### 页面跳转逻辑

```
Input 页面：
  - "查看汇总" (0-1人) → 直接跳 'summary'
  - "分配账单" (2+人) → 跳 'assign'

Assign 页面：
  - "返回" → 跳 'input'
  - "查看结果" → 跳 'summary'

Summary 页面：
  - "返回" → 跳 'input' (0-1人) 或 'assign' (2+人)
```

### 初始状态

- `currentStep: 'input'`（不再是 'setup'）
